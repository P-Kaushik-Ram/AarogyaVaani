# Android showcase

These captures show AarogyaVaani running on Android during prototype testing. Today and Dose alert show fictional reminders. Talk and Language and voice show settings and controls without reminder or transcript data.

| Screen | What to look for |
| --- | --- |
| [Today](today-dashboard.png) | The next scheduled reminder and the Taken, Skipped and Pending states on an isolated Android emulator. |
| [Talk](talk-voice-entry.png) | The microphone listening state and the prompt to review the recognized text on a physical device. |
| [Dose alert](dose-alert.png) | Taken, Snooze and Skip actions after opening a notification for a test reminder on a physical device. |
| [Language and voice](language-selection.png) | Six language choices and their beta and voice readiness labels on a physical device. |

Talk and Language and voice were documented by a project collaborator during the shared prototype demo. The images show screen states from that test session.
